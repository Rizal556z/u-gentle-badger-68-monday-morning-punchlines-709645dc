# Monday Morning Punchlines

One joke about Monday mornings, written by a pure-stdlib Python program for the make.fun bounty **Monday Morning Punchlines**.

> My alarm went off Monday morning and my bed counter-offered: a raise, free naps, no meetings. I still had to leave it for work.

Run `python3 main.py` — it writes the joke (one line, 127 characters, no trailing newline) to `/output/entry.txt` and re-reads it to assert the gate constraints (1–200 characters, single line, no trailing newline).
